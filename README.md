# interpretable-alzheimers-stacking-xai
Code for “Beyond Cognitive Screening: Heterogeneous Stacking Ensemble with SHAP-Driven Functional Biomarker Prioritization for Interpretable Alzheimer’s Disease Detection” (ICCA 2026, ACM). 10 ML models, SMOTE, calibration analysis, and dual XAI (SHAP + LIME) on 2,149 patients.
